# Where We Are

WordPress plugin – place a pin for your company location on a map.

- [Plugin page on WordPress.org](https://wordpress.org/plugins/where-we-are/)
- License: GPL v2

## Description

Allows administrators to mark their company location on a map with a pin, display a company slogan, and provide directions from the visitor's location to the company.

See [readme.txt](readme.txt) for full details, changelog, and installation instructions.
